# championcross 漫画下载器（comic-download-ultra）

基于 https://github.com/xuyanhenry/championcross-download 的思路重构而来（重构过程借助 DeepSeek V4 Flash 辅助）。

针对 https://championcross.jp/ 的命令行下载工具，**仅用于下载该站点对登录用户当前免费公开（含限时免费）的话数**。

> 本工具不绕过任何付费限制：未免费 / 需付费的话数一律跳过。
> 能否下载完全取决于站点当前是否允许你的账号免费阅读。

## 使用须知
1. 双击 comic-download-ultra.exe，按提示操作。
2. 需自备 championcross 账号并自行登录（工具不内置任何账号）。
3. 登录、访问可能需要日本地区网络环境。
4. 保存位置默认是桌面新建的漫画同名文件夹，也可自定义。

## 源文件说明
- comic-download-ultra.py —— 本体工具。
- build-ultra.bat —— 打包为 exe（与 py 放同一文件夹，双击运行）。
- discover.py —— 话数目录检测工具（调试用）。
- debug_labels.py —— 标签检测工具（调试用）。
